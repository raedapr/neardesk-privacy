# NearDesk privacy policy

The privacy policy for NearDesk (the phone app for Android and iPhone and the
Windows PC app), in English and Arabic.

Live page: https://raedapr.github.io/neardesk-privacy/
(Arabic: https://raedapr.github.io/neardesk-privacy/#ar)

This repository only hosts the static page (`index.html`) with the NearDesk
logo (`neardesk-logo.png`) and its icons (`favicon.ico`, `favicon-64.png`,
`apple-touch-icon.png`). It has no scripts, external fonts or trackers. GitHub Pages serves it from the root of the
`main` branch; `.nojekyll` makes Pages publish the files as they are.

Questions about privacy: raed1dev@gmail.com
